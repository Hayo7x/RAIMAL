# Presentation design assets

Snapshot saved 8 October 2026. The visual revision is a draft awaiting final visual QA; the initial deck is also preserved.

- **original-assets/**: RAIMAL and KFUPM logos, Sentinel imagery, published model figures and prototype zone output.
- **editable/**: complete PowerPoint files. Reuse native charts, tables, diagrams, map polygons and layouts by copying them from these decks.
- **previews/**: every slide as a PNG, separated into initial and visual-draft versions.
- **design-system/**: brand guidelines, CSS/JSON tokens and presentation-specific palette, typography and canvas settings.
- **source/**: original authoring scripts and captured chart data. These are archival source snapshots; scripts retain their original workspace and runtime paths and are not standalone installers.
- **powerpoint-parts/**: extracted embedded images, chart XML, workbooks and themes. Keep chart relationship files together; use the editable decks for convenient reuse.
- **reference/**: presentation plans and speaker notes.
- **SOURCES.md**: source links, attribution and evidence boundaries.
- **manifest.json**: file sizes and SHA-256 hashes for verification.
